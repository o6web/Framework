# Framework

Small framework of classes used by O6 Web Properties websites.

## Installation

Simply add a dependency on o6web/framework to your composer.json file if you use [Composer](https://getcomposer.org/) to manage the dependencies of your project:

```sh
composer require o6web/framework
```

Although it's recommended to use Composer, you can actually include the file(s) any way you want.
